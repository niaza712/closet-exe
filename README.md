# Closet.exe

A retro, 90s-computer digital closet inspired by Cher's iconic closet from the movie Clueless. Browse outfits on an illustrated paper doll, pull looks from a lookbook, and ask the stylist to dress you for a plan like "brunch with the girls in the west village" or "rainy day chic."

## Features

- **Dressing room:** flip through extras, tops, layers, bottoms, shoes and bags on the doll with the arrow buttons or your keyboard's arrow keys.
- **Match check:** a meter scores each outfit's colors and prints.
- **Stylist:** type where you're going and it builds an outfit from the closet, then suggests pieces worth buying. Quick picks include Fall in the Hudson Valley, Walk in Hyde Park, Brunch with friends, Rainy day chic, University, Date night, Drinks with the girls, Weekend brunch, Interview, Chalet weekend and Airport.
- **Shop the look:** every piece links to search results on Revolve, FWRD, Nordstrom and Google Shopping.
- **Lookbook:** 14 ready-made outfits. Save your own combinations too.
- **Add your own clothes:** upload a photo and it's placed on the doll.

## How it's built

It's a single `index.html` file written in plain HTML, CSS and JavaScript, with no dependencies. The clothes are drawn in code as SVG, layered on an illustrated doll. In this public version, the stylist matches your words against tags on each piece, like the season, the setting and how dressy it is.
